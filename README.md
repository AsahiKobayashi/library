# library
競技プログラミング向けライブラリ for Java
# data-structures / データ構造

|名称|説明|
|:-:|:-:|
|**SegmentTree**|区間取得、単一更新を ***O(logN)*** で行います|
|**DualSegmentTree**|単一取得、区間更新を ***O(logN)*** で行います|
|**LazySegmentTree**|区間取得、区間更新を ***O(logN)*** で行います|

|名称|説明|
|:-:|:-:|
|**UnionFind**|集合の統合、取得を ***O(α(N))*** で行います|
|**WeightedUnionFind**|辺に重みを持ち、集合の統合、取得を ***O(α(N))*** で行います|
